Nagavalli
Botanical Name :

  • Piper betle

    • Family Name :

  • Piperaceae

    • Local Name :

  • Nagavalli / Paan

    • Vernacular Name :

  • Hindi – Paan

  • English – Betel Leaf

    • Habitat :

  • Grows in tropical and subtropical regions

  • Cultivated in moist, shaded areas; requires support for climbing


    • Morphology :

  • Evergreen climbing vine

  • Leaves: Heart-shaped, glossy, aromatic

  • Stem: Slender, jointed

  • Flowers: Small, arranged in spikes

  • Roots: Adventitious


    • Useful Parts :

  • Leaves


    • Chemical Constituents :

  • Essential oils

  • Tannins

  • Alkaloids


    • Actions :

  • Carminative

  • Stimulant

  • Antimicrobial

  • Digestive


    • Properties :

  • Improves digestion

  • Freshens breath

  • Antibacterial

  • Mild stimulant


    • Indications :

  • Indigestion

  • Bad breath

  • Cough

  • Wounds (External use)


    • Dose :

  • Leaves: 1–2 fresh leaves

  • Juice: 5–10 ml


    • Formulations :

  • Nagavalli Patra Swara
